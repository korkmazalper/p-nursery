# Project User Stories

1. **User Registration:** As a new user, I want to create an account using my username, email, and password so that I can access personalized features.
2. **User Login:** As a registered user, I want to log in using my email and password to access my saved data.
3. **Home Feed:** As a user, I want to view a list of items fetched from an external API on the home screen.
4. **Item Details:** As a user, I want to click on an item from the home screen to view its detailed information.
5. **Favorites / Local Storage:** As a user, I want to save/favorite items so that they remain accessible even after restarting the app.
6. **Settings Menu:** As a user, I want to access a settings menu via a navigation icon to customize app options.
7. **Settings Screen:** As a user, I want to configure my profile and app preferences in the settings screen.
8. **Notification Setup:** As a user, I want to enable/configure local notifications in the app settings.
9. **Notification Alerts:** As a user, I want to receive a local notification alert when triggered by a specific action.
