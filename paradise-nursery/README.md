# Paradise Nursery - Houseplant Shopping Application

Paradise Nursery is a React and Redux-based e-commerce front-end application for browsing and purchasing houseplants.

## Features
- Interactive Landing Page with company details and navigation.
- Product Listing Page featuring houseplants divided into 3 distinct categories.
- Dynamic Redux-powered Shopping Cart with quantity adjustments, item deletion, dynamic item counters, and cost calculations.
- Responsive Header with Navigation and Cart Badge.

## Project Structure
- `src/App.jsx` - Main application wrapper and landing page navigation.
- `src/AboutUs.jsx` - Component describing Paradise Nursery.
- `src/ProductList.jsx` - Plant catalog with category display and "Add to Cart" functionality.
- `src/CartSlice.jsx` - Redux Toolkit slice managing cart state.
- `src/CartItem.jsx` - Detailed shopping cart view with total calculations.
- `src/App.css` - Custom styling including background image and component layout.
